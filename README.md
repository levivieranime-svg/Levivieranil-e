# Vivier Animée — prototype avancé

## Lancer le prototype
1. Décompressez `vivier_animee_pro.zip`.
2. Ouvrez `index.html` dans un navigateur récent (Chrome, Safari, Firefox).
3. Testez la recherche, les filtres, les favoris, le profil de démonstration et la publication d'une annonce locale.

## Ce que cette version comprend
- Interface responsive ordinateur/mobile, style plateforme d'emploi.
- Recherche et filtres d'offres.
- Détail d'une annonce, favoris enregistrés dans le navigateur.
- Formulaire de profil animateur de démonstration.
- Formulaire de publication d'annonce de démonstration.
- Pages ressources et espace structures avec prix indicatifs.
- Parcours de candidature simulé.

## Limites importantes
Ce prototype est un fichier web local. Les annonces d'exemple sont fictives. Les profils, favoris, annonces ajoutées et candidatures simulées restent dans le navigateur utilisé. Il n'y a pas de serveur, de comptes sécurisés, de base de données partagée, de vérification de diplômes, d'envoi réel de candidatures, de paiement, ni de publication publique.

## Pour une véritable mise en production
Il faudra notamment un backend et une base de données, authentification et rôles, stockage sécurisé, validation des offres et profils, notifications e-mail, paiement d'abonnements, journalisation, sauvegardes, modération, conformité RGPD, mentions légales/CGV et vérification des obligations juridiques applicables au modèle retenu. Ne pas utiliser les annonces fictives comme offres réelles.
